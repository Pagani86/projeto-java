# Sistema de Cadastro de Produtos (Java)

## 📌 Descrição

Este projeto foi desenvolvido durante a disciplina de Programação Orientada a Objetos com o objetivo de aplicar os principais conceitos da linguagem Java. A aplicação consiste em um sistema simples de cadastro e gerenciamento de produtos executado via console.

O programa permite criar objetos do tipo **Produto**, armazenando informações como nome, preço e quantidade em estoque. Além disso, disponibiliza operações para entrada e saída de produtos do estoque, atualizando automaticamente a quantidade disponível.

Embora seja um projeto acadêmico, ele foi desenvolvido para consolidar conceitos fundamentais da programação orientada a objetos, servindo como base para aplicações mais complexas.

## 🚀 Funcionalidades

* Cadastro de produtos.
* Exibição das informações do produto.
* Atualização da quantidade em estoque.
* Entrada de produtos no estoque.
* Saída de produtos do estoque.
* Cálculo automático do valor total em estoque.
* Interface simples via terminal (console).

## 🛠️ Tecnologias Utilizadas

* Java
* Programação Orientada a Objetos (POO)
* IDE (Eclipse/IntelliJ ou VS Code)

## 📚 Conceitos Aplicados

Durante o desenvolvimento foram utilizados diversos conceitos importantes da linguagem Java:

* Criação de classes e objetos.
* Encapsulamento de atributos.
* Construtores.
* Métodos de instância.
* Modificadores de acesso.
* Organização do código em múltiplas classes.
* Manipulação de entrada de dados pelo teclado.
* Utilização de tipos primitivos e objetos.
* Cálculos utilizando métodos da própria classe.

## 📂 Estrutura do Projeto

O projeto é organizado de forma simples:

* **Produto.java**: contém os atributos e métodos responsáveis pelas operações do produto.
* **App.java** (ou Main.java): responsável pela interação com o usuário, leitura dos dados e chamada dos métodos da classe Produto.

## 🎯 Objetivo

O principal objetivo deste projeto foi praticar os fundamentos da Programação Orientada a Objetos em Java, entendendo como dividir responsabilidades entre classes, criar métodos reutilizáveis e manipular objetos durante a execução do programa.

Esse projeto serviu como base para o aprendizado de conceitos mais avançados da linguagem, como herança, polimorfismo, coleções e interfaces, estudados posteriormente ao longo do curso.
